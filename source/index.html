Source code

The engine behind tfatftd.xyz, and the PCSX2 graphics renderer it uses for high resolutions.

Download source (version 3.15.2, 3.6 MB)

Contains the engine (ps2-web-recomp with this site's changes), the PCSX2 GS renderer source it uses, the new WebGPU code that runs PCSX2's renderer in the browser, build notes, credits and licenses.

No game data

There's no disc image, game code, textures or saves in here. The scripts turn a disc you own into a web page on your own machine. The Fast and the Furious belongs to its owners (Eutechnyx, Bandai Namco, Universal); this is a fan project, not affiliated with or endorsed by them.
